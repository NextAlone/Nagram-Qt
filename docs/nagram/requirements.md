# Nagram Desktop 功能需求

本文件从旧实现分支（`main`，基于上游 7.2.8）的 `docs/nagram-settings.md` 第 1–3 节提取，只保留**需求与行为约束**；旧实现的进度、验收记录、稳定键清单和存储细节已移除。实现方式、存储、路线见 [设计与路线](design.md)，逐项来源核对见 [功能与配置目录](feature-catalog.md)。

在 `nagram-next` 分支上，下列功能均视为**未实现**，按设计文档的里程碑重新交付。

## 1. 范围

需求核对范围为 2026-09-13 的 Nagram iOS、Nagram Android 与桌面补充配置源码，覆盖增强功能、配置声明、设置页面、结构化配置和无开关操作。普通 Telegram 功能不重复列为新增功能；README 中的历史说明只作线索，以配置和调用点为准。

[完整功能与配置目录](feature-catalog.md) 是本需求的组成部分：逐项列出基础配置的功能、原始类型/默认值、桌面去向；另列结构化模型、菜单动作、非配置功能与排除项。目录中的原始名称用于核对语义，**不是未来 Qt 存储键的承诺**，原始默认值也不是桌面默认值。

桌面范围约定：

- 排除双击消息动作及无编辑权限时的双击替代动作，不定制或覆盖 Qt 原生双击行为。
- 排除点击消息行代替长按、聊天左右滑、下拉归档、滑动进入画中画、手机返回手势、底栏布局、前后摄像头选择、振动/距离传感器、移动推送与厂商系统服务。
- 滚轮到达聊天边界后进入下一频道/话题的控制具有桌面意义，保留已接入的两项配置；不能和手机左右滑操作混为一项。
- 桌面已有的发送快捷键、撤销/重做、主题、自动下载、媒体解码、基础翻译、账号、代理等优先复用已有能力。原生入口不在 Nagram 页面重复添加。
- 适用性与实现成熟度分开：条件纳入项必须先验证 Qt/API/平台能力，不能因为有同名字段就显示为可用。

## 2. 信息架构与统一约定

设置页使用以下六个顶层分组；随着消费者落地，在组内增加真实子页面。未实现功能只在设计中列出，不进入开关、快捷操作或搜索结果。

| 当前顶层分组 | 未来子页面及设计编号 |
| --- | --- |
| 外观 | F01 品牌与主题；F02 聊天列表与导航；F03 消息显示；F18 通知呈现 |
| 聊天 | F04 输入与文本；F05 消息菜单；F14 资料与管理 |
| 媒体 | F06 贴纸、媒体与音频；F13 消息截图 |
| 隐私 | F10 隐私与内容处理；F11 回执与在线状态；F12 本地消息历史 |
| 翻译 | F07 翻译与文本服务；F08 语音转写 |
| 高级 | F09 过滤规则；F15 网络与传输；F16 链接及外部集成；F17 配置管理与诊断 |

作用域缩写：`D` 本机安装数据目录；`A` 账号；`C` 对话；`T` 话题；`S` 当前操作/临时会话。默认外观为 D，网络身份、历史、规则及对话数据为 A/C/T。包含 Peer ID 的对象必须带账号，禁止跨账号串用。

所有新增行为默认关闭或继承 Qt 现状；显示型选项默认保持上游显示；比例默认 100%；排序默认上游；自定义集合默认不覆盖上游。下文范围值是桌面提案，不代表已通过性能验证。

配置页面显示当前值；共通的作用域、默认行为及生效方式集中说明。含义明确的开关只显示标题，不逐项重复描述；仅在存在重要范围、优先级、限制、账号差异或延迟生效时保留说明。数值项说明范围和继承语义。所有 Nagram 设置页面均不提供单项、分类或全局“恢复默认/重置”入口，后续新增设置也遵守此约定；用户直接修改原控件的值。即时刷新应通过现有响应式 UI 完成；影响解码器、字体或网络会话的变更须明确提示重新打开/重启。失败保留旧有效配置并显示原因，不静默降级或写回默认覆盖用户数据。

所有 Nagram 配置文案默认随版本内置英文、简体中文和繁体中文。新增标题、说明、分组和操作时，必须同时提供英文、简体中文和繁体中文，确保键和占位符一致；文件布局见设计文档。简繁文本按当前界面语言及其基础语言选择；未覆盖的语言使用英文。内置文本作为缺失键的默认值，不写入云端语言缓存，也不覆盖语言包或自定义文件中显式提供的翻译。

语言代码先统一大小写和分隔符，再交给 Qt 识别脚本，兼容 `zh-hant`、`zh_TW`、`zh_Hant_HK` 等形式。须有自动检查覆盖三语键与占位符一致、语言代码写法、云端/自定义语言包覆盖与删除回退、基础语言继承。

## 3. 桌面功能需求

<a id="f01"></a>

### F01 品牌、主题与基础外观

D；复用 Qt 主题、缩放、主字体与图标选择。新增气泡／头像圆角、气泡尾部、引用颜色、主菜单标题／顺序／显隐／节日装饰、界面半角符号，以及忽略对话自定义主题和壁纸。圆角 0 表示继承，10–100 为主题半径百分比，重启后应用；列表与消息仍使用同一套 Qt 样式。

主菜单头像沿用全局头像形状。开关样式保持 Qt 控件，不引入第二套控件库。核对调用点后更正两项适用性：Android `ProfileGalleryBlurView` 的大头像按钮模糊层在 Qt 中不存在，排除该选项；音乐封面自适应颜色依赖音乐封面获取模块，归入外部媒体后端的条件纳入范围。手机 Liquid Glass、软键盘、状态栏透明度、性能设备伪装不进入本组。

### F02 聊天列表、文件夹与导航

| 配置族 | 提议字段/类型与默认 | 行为及限制 |
| --- | --- | --- |

| 文件夹标签 | `display=inherit/text/icon/both`、`compact=false`、`hideUnreadCount=false` | 标签、未读计数、徽标分别控制 |

| 最近会话 | `recentChats=false`、本机列表、清空动作 | 用侧栏/快捷菜单进入，排除长按标签触发；历史按账号隔离 |
| 主菜单 | 个人资料、机器人、新群、新频道、联系人、通话、收藏、主题、设置、代理、添加账号、最近转发 | 有序可见性集合，默认上游；设置入口始终可达 |
| 会话边界 | 禁止滚动进入下一频道/话题，默认 false | 鼠标滚轮/触控板适配，仍允许显式导航 |
| 聊天顶部工具栏 | `enabled=false`；动作集合 | 搜索、媒体、置顶、跳到开头、静音/取消静音、清缓存；复用 Qt 原生入口，清理仍需确认 |
| 阅读位置 | 保存滚动位置、返回历史、刷新保持最新边界 | 保存位置为账号+对话+话题状态；只有刷新前位于底部才保持底部 |

### F03 消息显示与信息密度

D，必要时允许 A/C 覆盖。支持时间戳秒、转发原始时间、服务消息时间、消息 ID、精确数字、已编辑标记、发送者在线/最近在线提示、已读 tooltip、剧透直接显示、消息宽度、频道底部按钮、快速转发入口、简化引用、底部状态图标、反应可见性、动态与推荐入口。

- 时间戳秒与原始转发日期为 bool；时间格式跟随上游语言/时区。在线信息只显示 API 已提供的值，不推算被隐藏的精确在线状态。
- 消息宽度 `inherit` 或比例 50–400%，默认 inherit；`wideChannelPosts` 仅限频道，通用宽度倍率不能重复叠乘。
- 反应使用私聊/群组/频道三个可继承 bool；现有 `hideReactions` 为全局总开关，开启时隐藏全部，关闭时才读取分类覆盖。
- 频道底部按钮为 `inherit/hidden/mute/discuss`；无讨论群时保持可用的替代动作。输入框“发送身份”按钮归 F04；快速分享按钮与宽消息分别控制，不能复用一个含混键。
- 可见性集合覆盖相似频道折叠/隐藏、赞助消息/代理赞助入口、Premium 星标与头像动画、Stars 订阅提示、到期/升级/节日/恢复提示、生日、精选表情/贴纸/GIF、收藏表情标签/搜索标签、频道推荐、快捷标签、分享手机号提示、待办付费提示、空 Stars 按钮与礼物。默认沿用上游，仅控制本地呈现。

### F04 输入、格式与文本处理

D + S。格式菜单集合包括粗体、斜体、等宽、删除线、下划线、引用、剧透、链接、提及、清除格式、撤销与重做。复用 Qt 文本实体和编辑栈；键盘快捷键与标准文字选择保持可用。

支持格式工具栏、Markdown 开关、Markdown 链接解析、默认代码语言、代码高亮入口、发送/编辑/阅读三个独立的中西文间距开关。阅读时只生成显示派生值，不修改消息原文；发送与编辑时保护代码、链接、提及及实体偏移，变换后须能撤销。

输入框按钮用可见性集合：附件、命令、表情、录音、自动删除、礼物、AI 编辑、机器人打开、发送身份；附件/表情悬浮弹窗独立 bool。隐藏按钮不禁用对应快捷键。输入占位文案可选择群名、当前发送身份，默认继承。点击 bot 命令“立即发送/填入草稿”默认继承，后者应允许用户审核。

`Enter/Ctrl+Enter` 发送方式直接使用 `Core::Settings::sendSubmitWay`，不新增 `nagram.sendWithReturnKey`。手机新 Markdown 解析器的版本开关不迁移，Qt 只保留一套解析实现。

<a id="f05"></a>

### F05 消息菜单、转发与批量操作

D 的有序动作目录 + S 的操作参数。动作的标准 ID、可用性和处理函数独立于可见性。可见性为 `inherit/hidden/visible/modifier`；modifier 在 macOS 用 Cmd/Option，在其他桌面平台用对应修饰键，并显示提示。隐藏不等于授权，操作仍检查会话权限、消息类型和当前状态。

完整动作目录见附录，包括回复、编辑、引用/无引用转发、复读/复制式复读、合并消息、反向回复、快捷评价文本、复制文本/图片/链接、翻译/朗读、收藏、媒体保存、媒体信息、下载清理、同作者搜索/选择、区间/全选、置顶/取消置顶、投票操作、计划消息、建议帖子、统计、举报、屏蔽、管理、消息详情、过滤、历史和截图。

- 复读确认、贴纸/GIF/语音/圆视频发送确认、通话确认均可独立设置，默认保持上游；不把菜单选中当作发送已成功。
- 转发策略：保留/隐藏来源、评论与转发先后顺序、快速选择目标、受保护消息复制式处理，须明确预览结果。
- 合并消息为 `off/text/forwardBundle` 等经 Qt 验证的枚举；不直接采用 Android 整数。批量收藏、取消置顶、同作者选择必须检查当前仍有效的消息集合，部分失效不能默默操作别的消息。
- 快捷评价支持两组自定义文本，默认空；填入草稿或明确发送动作，不自动回复。
- 危险动作（删除、举报、封禁）保留上游确认；偏好仅选择初始选项，不跳过确认。不迁移“跳过五秒撤销”的移动交互，Qt 的撤销机制保留。

<a id="f07"></a>

### F07 翻译、简繁转换与 LLM

D 的服务配置，A/C/T 的自动翻译覆盖，S 的发送前翻译目标。原有 Telegram 翻译与系统翻译优先复用；外部服务是显式选项，不能失败后自动切换服务发送内容。

服务候选完整覆盖：Telegram、系统原生、Google/Google CN/Google Cloud、Microsoft、Yandex、Transmart、DeepL/DeepL Free、可配置 DeepLX 和通用 LLM。候选不代表目前均可用；接入时分别验证请求格式、语言列表与错误处理。旧源代码中的模型名仅是当时默认值，不作为当前服务可用性推荐。

LLM 模型配置按 provider 实例保存：`id`、显示名、协议 `openai/anthropic/经验证的其他协议`、base URL、endpoint、model、凭据引用、系统提示词、翻译提示词、`useContext=false`、温度 `0…2`（默认 0.7，服务不支持时禁用）。模型候选兼容 OpenAI、Gemini、Groq、DeepSeek、xAI、Zhipu、Mistral、OpenRouter、Qwen、Moonshot、SiliconFlow、自定义；不为每家新建一套并行存储字段。支持模型列表读取、连接测试与错误信息，不能将测试直接发到聊天。

功能覆盖：消息/选中文本/输入框/Instant View 翻译、对话自动翻译、目标语言、原文与译文切换、发送前翻译回填草稿、简繁转换（阅读与输入分开）、正式程度、摘要入口。自动翻译为 `inherit/on/off`，覆盖顺序为 T → C → A → D → 默认；不直接复刻 iOS “关闭即删除”的两态存储。

LLM 上下文默认关闭；开启时展示会带出的消息范围及截断规则，设置可取消的请求。翻译不得自动发送草稿；语言、实体、引用与代码格式需保留。密钥只进入系统凭据库，错误日志不含密钥或正文。

<a id="f08"></a>

### F08 语音转写

D/A；默认 Telegram，候选 OpenAI-compatible。字段：provider、baseURL、endpoint、model、language（空=自动）、prompt（空）、credentialRef。转写模型不得从翻译模型推断。支持连接/测试音频、模型选择、取消、失败重试、输入格式与大小校验；接口限制由 provider 能力返回，不硬编码手机录音路径。

语音与视频的音轨提取复用 Qt 媒体管线；外部上传前告知使用的服务。返回文本在转写区域显示，不代发消息；本地缓存按账号与媒体标识隔离，清理时移除转写缓存。

<a id="f09"></a>

### F09 过滤、屏蔽与规则

A/C/T；默认关闭，规则顺序为空。覆盖总开关、聊天内开关、发出消息的本地显示过滤、屏蔽用户消息、本地隐藏作者集合、Zalgo 组合字符过滤、规则导入/导出、全局规则的对话排除、临时显示被过滤内容。

提议 `Rule`：`id`、title、pattern、enabled、caseInsensitive、reversed、action（mask/replace/hide；旧 maskMessage 兼容为 hide）、replacement、authorPeerId 可空、accountId、peerId/threadId 可空、order。屏蔽和替换只改变显示；过滤发出消息不等于修改已发消息或阻止发送。

必须先编译并显示定位错误；提供样例输入和命中/替换预览。跨端 ICU/Foundation 正则不保证一致，Qt 采用实际引擎并报告不兼容项；防止灾难性回溯阻塞 UI。多规则次序、隐藏优先级、实体偏移与恢复原文都须有明确测试。规则导入保留原值和禁用状态，不自动启用。

<a id="f10"></a>

### F10 隐私、内容处理与本地锁

D/A。显示层：隐藏手机号、禁止联系人的默认手机号分享、演示隐私模式（隐藏身份/预览/通知）、本地账号隐藏、设置页锁、系统解锁。隐藏手机号只改变本机界面，不能替代服务端隐私设置。

内容层：敏感内容开关仅在 Telegram 返回可调整时显示；跳过已允许内容的重复确认不能绕过年龄/服务端校验。强制复制/本地内容保护处理为条件纳入，限定客户端已收到且能解码的数据，不承诺恢复未下载、过期或服务端拒绝的数据。

本地高级外观能力与订阅分开，不显示为已购买 Premium，不伪造服务端权益；可用能力逐项校验后呈现。账号/设置锁默认关闭；凭据不进入普通偏好或导出。应急锁定/清理为独立明确动作，先设计作用范围和恢复限制，不作为普通开关触发自动删除。

<a id="f11"></a>

### F11 已读回执、在线与活动状态

A，可选择共享策略；默认保持上游发送行为。字段：sendReadMessages=true、sendReadStories=true、sendOnline=true、sendActivity=true、offlineAfterOnline=false、markReadAfterAction=inherit、scheduledSend=false、silentSend=never、viewStoryPrompt=false、presetEnabled=false、lockedFields=空集合。

支持消息/动态回执、在线状态、上传/输入/选贴纸状态、补发离线包、操作后标已读、定时发送、静音发送 `never/preset/always`、查看动态前提示、策略预设及子项锁定。共享策略与独立账号策略互切必须预览受影响账号，关闭预设恢复之前配置，不覆盖锁定字段。

“仅本地全部已读”与“向服务端同步全部已读”为两个显式动作；本地缓存和网络回执队列分别管理。不能通过临时翻转全局 bool 执行网络操作，避免并发账号、异步任务或撤销导致回执意外发出。重启、断线重连、发送消息、手动标已读、观看动态都须覆盖；不承诺服务端绝对不可见。

F03 的 hidePrivateChatActivities 隐藏对方活动提示，和本组是否向对方发送活动状态完全独立。主菜单和托盘的策略入口仅在本组实现完成后加入。

<a id="f12"></a>

### F12 本地删除消息与编辑历史

A/C/T；默认不保存。独立设置保存删除消息、保存编辑历史、是否包含机器人、删除消息半透明样式、删除/编辑标记。支持查看版本、查看已删消息、单对话清理和全部本地清理，不能宣称恢复安装前或未接收的消息。

历史正文、实体、媒体引用不是普通偏好：进入单独版本化的账号数据存储，复用现有加密/会话生命周期设施。实现前确定保留期限、容量、媒体是否缓存、退出账号如何处理和清理行为；这些是启用条件。历史不得默认同步或随“配置导出”泄露。删除失败必须提示，不能把 UI 消失当成已清理。

<a id="f13"></a>

### F13 消息截图与分享图

D 的样式偏好 + S 的选区。支持截图入口、背景、日期、反应、头部装饰、彩色回复、剧透展开、内置/云主题、强调色。默认使用当前主题并保持剧透隐藏；分享前展示最终预览，用户可逐次覆盖。

云主题引用包含账号、themeId、documentId、title；accessHash 属于内部引用，不显示为普通设置、不跨账号复用、不导出为通用配置。支持复制图像/保存文件；隐藏头像/姓名等演示偏好应在预览中可见，截图尺寸和批量消息数需按实际内存预算验证。

<a id="f14"></a>

### F14 资料、群管理与可见数据

D + A/C。支持用户/会话 ID（hidden/Telegram API/Bot API）、消息 ID、DC、注册日期、完整简介、姓名顺序、频道身份标记及别名、彩色管理头衔、在线/最近在线提示、波斯日历及拉丁数字、通话前确认、匿名身份切换、群管理快捷入口、投票前票数（仅 API 已提供）。

注册日期来源若为估算或第三方，明确标注估算/来源与不可用状态，不当作 Telegram 权威字段。DC 信息只显示可获取值。频道别名按账号+peerId 存储，不修改远端名称。

群组资料页入口集合完整包括：群类型、邀请链接、关联频道、反应、外观、历史可见性、话题、位置、成员、权限、管理员、加入申请、已移除用户、最近操作、社区、删除群及其他已有管理项；按权限和 Qt 当前能力展示。

删除对话框的默认选择可以包含封禁、举报、删除该用户全部消息、共同群处理、删除用户反应，默认全不选，必须保留逐次确认。批量管理、无成员建群、升级群组、全部解除屏蔽等优先使用已有操作并明确目标集合。

<a id="f15"></a>

### F15 网络、代理与传输

D/A；默认上游网络策略。支持上传/下载性能档位、增强文件加载、IP 策略、系统 DNS/自定义 DoH、备用地址请求、代理自动切换、VPN 感知、代理订阅/自动更新、代理备注/测试/排序/失效节点处理、导入/导出/二维码，以及可执行文件/压缩包的自动下载例外。

性能档位提议 `default/balanced/fast`；实际分片大小、并发数与请求速率在 Qt 基准测试后确定，不照抄手机常量，不绕过服务端速率限制。自动下载例外合并到已有自动下载规则，不影响显式下载。目录选择复用上游下载/缓存配置。

SOCKS5/MTProxy 及现有代理能力优先复用。VMess/Shadowsocks/SSR/Trojan、订阅格式（SIP008、v2rayN、Clash 等）仅作为条件接入目标：先决定外部代理程序或可维护的后端，不因旧 README 声称支持就引入未维护核心。公共代理没有默认远程来源，不自动订阅。VPN 检测依平台能力，检测失败必须显示未知。

<a id="f16"></a>

### F16 链接、网页应用与外部集成

D/A。支持链接预览默认开关、规则修正 URL、自动 inline bot、本地/远程规则启停、外部浏览器打开规则、网页自动登录开关、链接确认、网页应用窗口尺寸、网页兼容身份、地图预览服务、话题标签搜索初始范围。

链接与 inline bot 使用不同规则集。预览替换只影响预览 URL，保留用户原始文本；bot 规则包含 username、patterns、enabled、来源/版本、顺序；本地启用集合与禁用的远程规则集合分别保存。远程更新展示来源和差异，不覆盖本地规则；默认不请求外部元数据。跳过媒体预览不能变成未经确认自动发送。

网页兼容身份为逐站点可选项，默认桌面身份；窗口宽高使用可调整比例并遵守屏幕工作区。敏感授权和 Telegram 登录确认不受“关闭普通链接提示”影响。Android 地图 SDK、OpenKeychain 应用绑定、手机厂商 Live Photo 写入不直接迁移；跨平台文件格式或 GPG 集成另行提出具体需求后设计。

### F17 配置管理、同步、诊断与更新

D/A。提供搜索、修改项列表、配置导入导出、迁移报告、服务连接测试、版本及源码入口、诊断日志。云同步默认关闭；先做本地文件交换，再考虑受控云存储适配。iCloud 只可作为 macOS 可选后端，不能成为全平台基线。

导出使用版本化 allowlist，支持预览差异、未知项列表、类型/范围验证与整批原子提交。主题/规则/菜单模板与个人配置分开；密钥、账号会话、手机号、代理密码、锁凭据、消息历史、回执队列、最近会话、同步时间戳不进入默认导出。配置修改与导入只处理本设计管理的键，不清空登录和上游设置。

崩溃上传和自动更新当前在构建层关闭；启用前需独立服务、显式开关及数据范围说明。更新通道是发行配置；API ID/hash、测试 DC 是构建/开发配置，不作为普通用户运行时可调项。RPC 错误以可操作的错误码和说明呈现，不暴露凭据或正文。

### F18 通知呈现

## 4. 跨端语义合并

语义合并规则：iOS `stickerTimestamp=true` 与 Qt `hideStickerTimestamp=false` 方向相反；`hidePhoneInSettings/HidePhone` 映射到本地隐藏能力；各端自动翻译继承模型不同；同一个动作的菜单显示、动作参数与后台状态不能混成一个 bool。消息截图的 `showReactions` 与聊天反应不是同一作用域。所有转换必须按版本显式迁移，不按键名猜测。

## 5. 通用验收要求

每个选项接入前须确认：默认行为、切换生效、重启恢复、关闭后的行为还原、账号切换、继承/显式关闭、页面重开、搜索返回和无权限状态。UI 需覆盖多语言、深浅色和 125%/200% 缩放；文本变换需覆盖组合实体、代码、超长消息和撤销。

P2 的外部请求须测试取消、超时、凭据错误和不重复发送；正则须测试性能及不兼容表达式；结构化配置须测试坏数据、未知字段和幂等迁移。P3 需增加断线重连、跨账号、异步竞态、数据保留/清理、回退和外部能力不可用测试。

只有行为验收通过的项目才进入真实 UI。目录中的“纳入/合并”“条件纳入”和 P1/P2/P3 都是规划标识，不是已实现承诺；排除项只保留核对记录。

## 6. 功能包与优先级

优先级按**预期常用度、实现复杂度、依赖是否就绪和验证成本**共同判断；常用度是典型桌面聊天场景下的产品判断，没有使用遥测数据。复杂度只描述工程范围，不代表工期估算。

- **P1：先做。** 高频且局部，或可直接复用上游；优先形成可用的日常体验。
- **P2：随后做。** 常用但需要独立模块，或价值明确、使用面相对较窄；通常依赖 P1 的设置/动作基础。
- **P3：最后做。** 涉及协议状态、持久化历史、跨设备同步、外部服务生态或较强平台差异；先完成能力验证与专项设计。

复杂度：低＝局部 UI/已有 API 接入；中＝跨页面、文本实体、状态继承或结构化配置；高＝异步网络状态、敏感数据生命周期、复杂迁移、性能或跨平台后端。条件纳入项即使有优先级，也必须先满足本需求的能力门槛。排除项不分级、不进入队列；品牌和设置基础属于设计文档的 M0 里程碑。
