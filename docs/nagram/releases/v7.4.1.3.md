Nagram Desktop 7.4.1.3，基于 Telegram Desktop 7.4.1。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里列出相对上一个正式版 [7.3.5.2](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.3.5.2) 的全部变化，包括测试版 [7.4.1.1-beta](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.4.1.1-beta) 和 [7.4.1.2-beta](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.4.1.2-beta) 的内容。

功能主要在 macOS 上实际运行过，Windows 和 Linux 只通过了编译、单元测试和启动冒烟测试。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 或 [@OrIssuesBot](https://t.me/OrIssuesBot) 反馈。

## macOS 上改名为 Nagram Desktop

macOS 上的应用从 `Nagram.app` 改名为 `Nagram Desktop.app`，菜单栏和程序坞里也显示 Nagram Desktop。`Nagram` 这个名字留给基于 Telegram for macOS 的原生客户端，两者可以装在一起。数据目录、设置和登录状态都不变。

已经安装的 `Nagram.app` 更新到这一版后，第一次启动时会把自己改名为 `Nagram Desktop.app` 并重新打开。同一位置已经有 `Nagram Desktop.app`、或者没有权限改名（例如不是管理员账户）时保留原名照常使用，可以自己在“应用程序”文件夹里改名。

## 上游

升级到 Telegram Desktop 7.4.1（包含 7.4）。

- 机器人可以在聊天里显示 HTML 小组件。小组件运行在隔离的环境里，可以通过 Gram 钱包的 TON Connect 窗口请求付款和签名。
- 钱包：交易里的地址显示为等宽的胶囊；很小的法币金额至少保留一位有效数字。
- 新聊天视图里，点击附件按钮会弹出附件菜单。
- 本地化：文件大小单位、快捷键说明里的按键名和自定义语言包的名字都可以翻译，切换语言后归档的名字随之更新；自动删除的标记改用更短的说法。
- 布局：设置项的长标签改为换行而不是截断，右侧的值保持完整；滑块的刻度标签不再重叠；下载文件夹的选项、手机号确认框的文字会换行；通话气泡按标题和图标的宽度收窄；名字颜色设置里显示链接预览。
- 上游撤回了 7.3.5 里“在缩放不同的屏幕上，窗口位置恢复到工作区之外”的修复。
- 修复：Windows 上部分系统一启动就崩溃；没有主小程序的机器人打不开 `startapp` 链接；群组贴纸和表情设置框的副标题互换；以及打开动态归档、帖子搜索、年龄验证、“全部已读”菜单、联系人框头像菜单、只有视频的链接预览时的几处崩溃。

## 新增

- Instant View 和 Telegraph 文章可以整页翻译：窗口右上角的菜单里，“分享”下面多了“翻译”，翻译后这一项变成“显示原文”。翻译走“Nagram 设置 → 翻译与转写服务”里选的服务，目标语言是 Telegram 设置里的“翻译成”。代码块和公式不翻译。（许愿 #WD0001）
- 翻译服务新增 DeepLX：添加服务时选 DeepLX 预设，默认地址是本机的 `http://127.0.0.1:1188/`，可以改成自己的地址。（许愿 #WD0008）
- 资料页的 ID 单击就能复制：在“Nagram 设置 → 隐私与资料 → 在资料页显示 ID”里打开后，点资料页的 ID 行复制。（许愿 #WD0009）
- 数值设置改用滑块：文字消息宽度、最近贴纸数量、最近会话数量、贴纸大小、贴纸面板大小、小程序宽度和高度，和圆角一样拖动调节。消息宽度和最近贴纸数量可以勾选“跟随 Telegram”。以前手动输入的、落在两个刻度之间的值会原样保留，直到拖动滑块。
- 圆角可以调到直角：“Nagram 设置 → 界面 → 圆角与形状”里的消息气泡、头像、搜索框圆角可以调到 0%，重启后生效。（许愿 #WD0010）
- Windows 安装程序可以选简体中文和繁体中文。
- Linux 新增 RPM 安装包，可在 Fedora、RHEL、openSUSE 上安装。用 RPM 安装后由系统包管理器更新，应用内更新会关闭。（许愿 #WD0007）
- AUR 新增测试版包 `nagram-desktop-beta-bin`，跟随测试版和稳定版，与 `nagram-desktop-bin` 互相替换。（许愿 #WD0003）

## 修复

- Linux 上翻译服务的 API 密钥保存不了。现在存进系统的 Secret Service（GNOME Keyring、KWallet 等）；系统没有可用的凭据库、或凭据库拒绝访问时，会提示具体原因。
- “Nagram 设置 → 会话 → 会话排序”里的规则改为和顶栏按钮一样拖动排序，拖动时这一行跟随鼠标，其他行让开。
- 开启“点击机器人命令时先填入输入框”后，在输入框里输入 `/` 再从列表选命令，命令没有填进输入框。（反馈 #D0008）
- 登录多个账号时，切换账号会卡住然后闪退。（反馈 #D0005）
- Windows 上“已编辑”标记显示成一团认不出的图案。打开“‘已编辑’标记改用图标”后，现在画的是一支铅笔图标，不再依赖字体。
- 打开“阅读时在中西文之间加空格”或“阅读时简繁转换”后，选中一段文字引用回复，引用的内容和原文对不上。现在引用取的是原文里对应的那一段。
- Windows 上打开图片、视频时，查看器的背景会闪烁。这一项还没有在 Windows 上实际验证，仍有闪烁请反馈。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram Desktop 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram Desktop.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Arch Linux（AUR）

稳定版的包名是 `nagram-desktop-bin`，安装的就是本页的 Linux 发行包：

```bash
yay -S nagram-desktop-bin
```

想同时收到测试版，改装 `nagram-desktop-beta-bin`，它会替换掉 `nagram-desktop-bin`。这样装的由 pacman 更新，应用内的自动更新是关闭的。

### Nix

仓库自带 flake，安装的同样是本页的 Linux 发行包。仅 NixOS 可用（x86_64-linux），需要启用 flakes：

```bash
nix profile install github:NextAlone/Nagram-qt
```

程序在隔离的 FHS 环境里运行，由 Nix 更新，应用内的自动更新是关闭的。其他发行版上即使装了 Nix 也不要这样安装：包里不带图形驱动，找不到时程序一启动就退出。

AUR 和 Nix 的包在本版本发布后由 CI 更新，会比本页晚几分钟。

### Fedora、RHEL、openSUSE

```bash
sudo dnf install ./Nagram-7.4.1.3-linux-x86_64.rpm
```

openSUSE 用 `zypper install`。安装后运行 `Nagram`，由系统包管理器更新。包没有签名，安装本地文件时会提示跳过签名检查。

### 其他 Linux 发行版

解开 `tar.xz`，运行 `Nagram/Nagram`。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
