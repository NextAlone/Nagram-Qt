## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram Desktop 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram Desktop.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`，旁边的 `modules` 文件夹要一起保留。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Linux

- **压缩包**（`.tar.xz`）：解开后运行 `Nagram/Nagram`，旁边的 `NagramDesktop` 文件夹要一起保留。放在可写的位置时会自行更新。
- **RPM**（`.rpm`）：`sudo dnf install ./Nagram-7.4.7.1-beta-linux-x86_64.rpm`（openSUSE 用 `zypper install`）。安装后运行 `Nagram`，由系统包管理器更新。包没有签名，安装本地文件时会提示跳过签名检查。
- **AUR**：`nagram-desktop-beta-bin`。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
