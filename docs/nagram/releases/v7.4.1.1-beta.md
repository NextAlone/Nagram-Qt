Nagram Desktop 7.4.1.1 测试版，基于 Telegram Desktop 7.4.1。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里只列出相对 [7.3.5.2](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.3.5.2) 的变化。

这一版同步了上游从 7.3.5 到 7.4.1 的改动，Nagram 自己的功能没有变化。仍作为测试版发布：自动更新只推送给在“设置 → 高级”里打开了“安装测试版”的用户，包管理器（AUR、Nix、Homebrew）不会更新到这一版。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 反馈。

## 上游

升级到 Telegram Desktop 7.4.1（包含 7.4）。

- 机器人可以在聊天里显示 HTML 小组件。小组件运行在隔离的环境里，可以通过 Gram 钱包的 TON Connect 窗口请求付款和签名。
- 钱包：交易里的地址显示为等宽的胶囊；很小的法币金额至少保留一位有效数字。
- 新聊天视图里，点击附件按钮会弹出附件菜单。
- 本地化：文件大小单位、快捷键说明里的按键名和自定义语言包的名字都可以翻译，切换语言后归档的名字随之更新；自动删除的标记改用更短的说法；删除了界面上不会出现的文案。
- 布局：设置项的长标签改为换行而不是截断，右侧的值保持完整；滑块的刻度标签不再重叠；下载文件夹的选项、手机号确认框的文字会换行；通话气泡按标题和图标的宽度收窄；名字颜色设置里显示链接预览。
- 上游撤回了 7.3.5 里“在缩放不同的屏幕上，窗口位置恢复到工作区之外”的修复。
- 修复：
  - Windows：部分系统一启动就崩溃。
  - 打开 `startapp` 链接时，没有主小程序的机器人无法打开。
  - 群组贴纸和表情设置框的副标题互换了；转写评分菜单项高度为零；话题搜索请求失败后一直显示加载。
  - 在动态归档数量未知时打开它、帖子搜索里缓存了已删除的消息、无法解析年龄验证机器人、“全部已读”菜单比按钮存在得更久、在联系人框的头像菜单之后关闭它、缩小只有视频的链接预览时的崩溃。

## 安装包

| 平台 | 文件 |
| --- | --- |
| macOS（Apple 芯片与 Intel） | `Nagram-7.4.1.1-beta-macos.dmg`（磁盘镜像）、`Nagram-7.4.1.1-beta-macos.zip` |
| Windows x64 | `Nagram-7.4.1.1-beta-windows-x64-setup.exe`（安装程序）、`Nagram-7.4.1.1-beta-windows-x64.zip`（便携版） |
| Windows ARM64 | `Nagram-7.4.1.1-beta-windows-arm64-setup.exe`（安装程序）、`Nagram-7.4.1.1-beta-windows-arm64.zip`（便携版） |
| Linux x86_64 | `Nagram-7.4.1.1-beta-linux-x86_64.tar.xz` |

名字以 `td-update-` 开头的文件是给应用内更新用的，不需要手动下载。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Linux

解开 `tar.xz`，运行 `Nagram/Nagram`。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
