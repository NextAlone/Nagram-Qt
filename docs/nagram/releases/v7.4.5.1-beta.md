## 上游

升级到 Telegram Desktop 7.4.5 测试版。

### 新增

- 「动态」 | 可以发布动态，并保存为草稿；
- 「圆形视频」 | 发送前可以裁剪时长；
- 「机器人」 | 管理机器人时可以编辑多语言的简介和介绍，支持自动翻译缺少的语言；
- 退出登录前提供其他选项；
- 聊天内搜索的日历显示媒体预览；
- 按住 Alt 选择文字时按词选择；
- 系统媒体控件可以调节播放速度和视频音量。

### 改善

- Qt 升级到 6.12；
- 安装更新前再次校验已下载的更新包；
- 月份标题和大写标签按界面语言的规则处理；
- 多处长标签改为换行或缩小，不再被截断；
- 窗口在多个缩放不同的屏幕之间恢复时不再漂移；
- 语言包的大小上限提高到 4 MB。

### 修复

- 「频道」 | 跳转后未读标记不消失的问题；
- 「动态」 | 编辑草稿时图片翻转、视频图层被覆盖的问题；
- 已注销账号的聊天显示无法访问群组的文字的问题；
- 编辑含表情的消息时选区偏移的问题；
- 工作目录路径很长时启动崩溃的问题。

| 平台 | 文件 |
| --- | --- |
| macOS（Apple 芯片与 Intel） | `Nagram-7.4.5.1-beta-macos.dmg`（磁盘镜像）、`Nagram-7.4.5.1-beta-macos.zip` |
| Windows x64 | `Nagram-7.4.5.1-beta-windows-x64-setup.exe`（安装程序）、`Nagram-7.4.5.1-beta-windows-x64.zip`（便携版） |
| Windows ARM64 | `Nagram-7.4.5.1-beta-windows-arm64-setup.exe`（安装程序）、`Nagram-7.4.5.1-beta-windows-arm64.zip`（便携版） |
| Linux x86_64 | `Nagram-7.4.5.1-beta-linux-x86_64.tar.xz`、`Nagram-7.4.5.1-beta-linux-x86_64.rpm`（Fedora、RHEL、openSUSE） |

名字以 `td-update-` 开头的文件是给应用内更新用的，不需要手动下载。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram Desktop 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram Desktop.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Linux

- **压缩包**（`.tar.xz`）：解开后运行 `Nagram/Nagram`。放在可写的位置时会自行更新。
- **RPM**（`.rpm`）：`sudo dnf install ./Nagram-7.4.5.1-beta-linux-x86_64.rpm`（openSUSE 用 `zypper install`）。安装后运行 `Nagram`，由系统包管理器更新。包没有签名，安装本地文件时会提示跳过签名检查。
- **AUR**：`nagram-desktop-beta-bin`。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
