Nagram Desktop 7.3.3.2 测试版，基于 Telegram Desktop 7.3.3。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里只列出相对 [7.3.3.1-beta](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.3.3.1-beta) 的变化。

这一版同步了上游 7.3.3 之后开发分支上的改动。仍作为测试版发布：自动更新只推送给在“设置 → 高级”里打开了“安装测试版”的用户，包管理器（AUR、Nix、Homebrew）不会更新到这一版。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 反馈。

## 上游

同步 Telegram Desktop 开发分支（版本号仍是 7.3.3）。

- 会话列表搜索：
  - 新增“频道”标签，可以搜索已加入的频道、公开频道和频道帖子；“应用”标签可以搜索应用。
  - 照片、视频和语音消息标签里也能搜索。
  - 切换标签时保留搜索词，标签可以像聊天文件夹一样滑动切换。
  - 搜到的消息可以右键。
- 可以把文字拖到会话列表里的聊天上。
- 悬浮音频播放器的倍速按钮可以按住临时加速。
- 快捷键设置里可以右键重置或删除快捷键。
- 视频编辑器转 GIF 时限制大小。
- 触摸屏上滚动到底会回弹，继续拉动进入下一个聊天。
- 修复：
  - 投票的选项文字与票数重叠。
  - 媒体查看器里保存快捷键无效，失去焦点后快捷键失灵。
  - 图片编辑器里输入“?”弹出快捷键说明。
  - 视频编辑器发送的视频缺少静音标记；非 MP4 视频切换 GIF 时没有动画。
  - 从搜索结果打开聊天后，焦点仍留在搜索框里。
  - 代码块第一行的缩进丢失。
  - 从聊天菜单新建文件夹时无法创建邀请链接；清除会话数据后文件夹仍留在会话列表里。
  - 会话列表加载时重复显示已加入的频道。
  - 图片编辑器关闭时可能崩溃。
  - Windows 上的字体显示和滚动结束处理。

## 新增

- 多选消息后的复读和无引用转发：
  - 多选栏的“转发”后面新增“复读”“无引用复读”“无引用转发”“复制”四个按钮，带选中数量；所选消息不能转发时不显示，窗口太窄时从后往前隐藏。“频道中不提供复读”同样生效。
  - 多选后的右键菜单也提供这三项操作，与单条消息菜单一样默认隐藏，可以在消息菜单设置里打开。
  - “复读”把所选消息转发回当前聊天；“无引用复读”逐条作为新消息发送；“无引用转发”打开选择聊天窗口，转发时隐藏原发送者。用多选栏按钮复读或转发后会退出多选。
  - 打开“复读前确认”时会先询问。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Linux

解开 `tar.xz`，运行 `Nagram/Nagram`。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
