Nagram Desktop 7.3.0.1 测试版，基于 Telegram Desktop 7.3.0。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里只列出相对 [7.2.10.3](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10.3) 的变化。

这一版同步了上游从 7.2.10 到 7.3.0 的全部改动。功能在 macOS 上实际运行过，Windows 和 Linux 只通过了编译、单元测试和启动冒烟测试。因此先作为测试版发布：自动更新只推送给在“设置 → 高级”里打开了“安装测试版”的用户，包管理器（AUR、Nix、Homebrew）不会更新到这一版。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 反馈。

## 上游

升级到 Telegram Desktop 7.3.0。上游这一版的更新记录只写了“Money”，下面按上游的提交整理。

- 钱包（Money）：内置的 Gram 钱包，在单独的窗口里显示余额（可换算成法币）、交易记录和收藏品。入口只在 Telegram 服务端对账号开放时出现。
  - 收发 Gram：从主菜单、资料页或私聊的附件菜单发送，可以填 Telegram 用户、钱包地址或 `.ton` 名字，附带的留言默认加密；转账在聊天里显示为卡片。
  - 打开 `ton://` 转账链接会进入发送界面；支持用 TON Connect 连接外部应用，并在钱包里查看和断开已连接的应用。
  - 密钥：导入或查看恢复短语，开启或关闭加密备份；钱包密钥由本地密码保护，macOS 可用 Touch ID、Windows 可用 Windows Hello 解锁。设置本地密码时显示强度提示。
- 消息暂存：输入框里写到一半的消息（包括待发送的文件）可以先暂存起来，稍后取回，有对应的按钮和快捷键。
- 图片与视频编辑器：
  - 可以把聊天消息和链接预览放到画布上。
  - 可以加音轨并调节音量；视频片段可以在时间线上裁剪，时间线支持滚轮缩放和直接输入时间。
  - 画布可以扩展到图片之外，按住 Shift 拖动时吸附参考线，按 Backspace 删除选中的项目，新增快捷键说明。
- 小程序：外部窗口的菜单、全屏、弹窗和加载提示有多处改进；小程序打开链接和下载文件需要用户操作；Linux 上会询问媒体和位置权限。
- 富文本消息：链接按钮显示网址提示并可复制链接，识别 TON 地址，修正气泡边缘的宽度、圆角和边距。
- 其他：输入时机器人菜单按钮会收窄；更多对话框可以按 Enter 提交；调过颜色的主题可读性更好。
- 修复：
  - 多处崩溃：即时预览编辑器、图片编辑器、分享框搜索、聊天列表的视频头像、没有屏幕时的通知、共享媒体跳转等。
  - 读到损坏的应用设置时不再死循环。
  - 同时编辑时不再丢失最新的草稿。
  - 含相对日期的富文本消息不再卡死。
- 依赖：Qt 6.11.2、OpenSSL 3.5.9，WebRTC、ANGLE、xz、ada 等同步更新。

## 新增

- 注册时间估算：Telegram 没有提供某个用户的注册月份时，资料页按用户 ID 估算并标明“估算”，显示为“约”“早于”或“晚于”某个月份。开关仍是原来的“显示注册时间”。
- 托盘图标换成了新的 Nagram 图标，包括 macOS 菜单栏图标和单色图标的未读、静音状态。

## 修复

- 消息菜单里的“重复”现在立刻显示发出的消息，不再等服务器返回。带相册或隐藏来源的转发同样如此。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Linux

解开 `tar.xz`，运行 `Nagram/Nagram`。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
