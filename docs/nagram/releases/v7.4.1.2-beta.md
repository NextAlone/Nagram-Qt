Nagram Desktop 7.4.1.2 测试版，基于 Telegram Desktop 7.4.1。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里只列出相对 [7.4.1.1 测试版](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.4.1.1-beta) 的变化。

这一版是 Nagram 自己的新功能和修复，上游没有变化。仍作为测试版发布：自动更新只推送给在“设置 → 高级”里打开了“安装测试版”的用户。这一版开始提供 AUR 测试版包 `nagram-desktop-beta-bin` 和 Linux 的 RPM 安装包，这两样都是第一次发布；Nix、Homebrew 和 AUR 的 `nagram-desktop-bin` 只跟随稳定版，不会更新到这一版。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 或 [@OrIssuesBot](https://t.me/OrIssuesBot) 反馈。

## 新增

- Instant View 和 Telegraph 文章可以整页翻译：窗口右上角的菜单里，“分享”下面多了“翻译”，翻译后这一项变成“显示原文”。翻译走“Nagram 设置 → 翻译与转写服务”里选的服务，目标语言是 Telegram 设置里的“翻译成”。代码块和公式不翻译。（许愿 #WD0001）
- 翻译服务新增 DeepLX：在“Nagram 设置 → 翻译与转写服务”里添加服务时选 DeepLX 预设，默认地址是本机的 `http://127.0.0.1:1188/`，可以改成自己的 DeepLX 地址。需要访问令牌时开启密钥并填入。（许愿 #WD0008）
- 资料页的 ID 单击就能复制：在“Nagram 设置 → 隐私与资料 → 在资料页显示 ID”里打开后，点资料页的 ID 行复制并提示。（许愿 #WD0009）
- 圆角可以调到直角：“Nagram 设置 → 界面 → 圆角与形状”里的消息气泡、头像、搜索框圆角现在可以调到 0%，重启后生效。（许愿 #WD0010）
- Linux 新增 RPM 安装包 `Nagram-7.4.1.2-beta-linux-x86_64.rpm`，可在 Fedora、RHEL、openSUSE 上安装。用 RPM 安装后由系统包管理器更新，应用内更新会关闭。（许愿 #WD0007）
- AUR 新增测试版包 `nagram-desktop-beta-bin`，跟随测试版和稳定版，与 `nagram-desktop-bin` 互相替换。（许愿 #WD0003）

## 修复

- 开启“Nagram 设置 → 输入与发送 → 点击机器人命令时先填入输入框”后，在输入框里输入 `/` 再从列表选命令，命令没有填进输入框。（反馈 #D0008）
- 登录多个账号时，切换账号会卡住然后闪退。原因是“启动时打开的文件夹”在聊天列表还没显示出来时就播放了切换动画。（反馈 #D0005）
- Windows 上“已编辑”标记显示成一团认不出的图案：打开“Nagram 设置 → 消息 → ‘已编辑’标记改用图标”后，现在画的是一支铅笔图标，不再依赖字体。
- 打开“Nagram 设置 → 消息 → 阅读时在中西文之间加空格”或“阅读时简繁转换”后，选中一段文字引用回复，引用的内容和原文对不上，其他客户端提示找不到原始引文。现在引用取的是原文里对应的那一段。
- Windows 上打开图片、视频时，查看器的背景会闪烁。现在 Windows 上的查看器窗口不再是半透明的，其他平台不变。这一项还没有在 Windows 上实际验证，仍有闪烁请反馈。
- 发布时某个平台没有构建成功，频道帖子里就会缺这个平台的安装包，7.3.5.1 测试版的帖子缺了 macOS。现在要等所有平台都构建完才发帖。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Linux

- **压缩包**（`.tar.xz`）：解开后运行 `Nagram/Nagram`。放在可写的位置时会自行更新。
- **RPM**（`.rpm`）：`sudo dnf install ./Nagram-7.4.1.2-beta-linux-x86_64.rpm`（openSUSE 用 `zypper install`）。安装后运行 `Nagram`，由系统包管理器更新。包没有签名，安装本地文件时会提示跳过签名检查。
- **AUR**：`nagram-desktop-beta-bin`。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
