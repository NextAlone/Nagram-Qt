## 上游

升级到 Telegram Desktop 7.4.6（包含 7.4.5 测试版）。

### 新增

- 「动态」 | 可以发布动态，并保存为草稿；
- 「动态」 | 文字工具可以插入表情，贴纸面板新增表情和 GIF；
- 「圆形视频」 | 发送前可以裁剪时长；
- 「机器人」 | 管理机器人时可以编辑多语言的简介和介绍，支持自动翻译缺少的语言；
- 「机器人」 | 资料页显示小程序预览；
- 「机器人」 | 可以邀请用户到与自己机器人的私聊；
- 「礼物」 | 可以在「钱包」里出价、出售、改价和下架链上礼物；
- 「礼物」 | 礼物市场可以按 Gram、星星和 Fragment 筛选；
- 「我的资料」 | 新增照片、动态和编辑操作；
- 「语音搜索」 | 全局语音搜索可以匹配话题标题；
- 退出登录前提供其他选项；
- 聊天内搜索的日历显示媒体预览；
- 搜索栏的锁定按钮可以直达密码锁设置；
- 按住 Alt 选择文字时按词选择；
- 系统媒体控件可以调节播放速度和视频音量。

### 改善

- HTML 小组件改用 Nova 引擎，在单独的受限进程中运行；
- Qt 升级到 6.12；
- 安装更新前再次校验已下载的更新包；
- 文件夹图标可以使用标题开头的单色表情；
- 动态数量达到上限时改为显示 Premium 上限说明；
- 嵌套的折叠引用块可以展开；
- 月份标题和大写标签按界面语言的规则处理；
- 多处长标签改为换行或缩小，不再被截断；
- 窗口在多个缩放不同的屏幕之间恢复时不再漂移；
- 语言包的大小上限提高到 4 MB。

### 修复

- 「频道」 | 跳转后未读标记不消失的问题；
- 「动态」 | 编辑草稿时图片翻转、视频图层被覆盖的问题；
- 「动态」 | 动态栏为空时发布按钮消失的问题；
- 「视频编辑」 | 从大视频裁剪的片段发送失败的问题；
- 「视频编辑」 | 打开编辑器时时间轴为空的问题；
- 已注销账号的聊天显示无法访问群组的文字的问题；
- 编辑含表情的消息时选区偏移的问题；
- 工作目录路径很长时启动崩溃的问题；
- Linux 上窗口内容的位置计算错误的问题。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram Desktop 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram Desktop.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`，旁边的 `modules` 文件夹要一起保留。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Arch Linux（AUR）

稳定版的包名是 `nagram-desktop-bin`，安装的就是本页的 Linux 发行包：

```bash
yay -S nagram-desktop-bin
```

想同时收到测试版，改装 `nagram-desktop-beta-bin`，它会替换掉 `nagram-desktop-bin`。这样装的由 pacman 更新，应用内的自动更新是关闭的。

### Nix

仓库自带 flake，安装的同样是本页的 Linux 发行包。仅 NixOS 可用（x86_64-linux），需要启用 flakes：

```bash
nix profile install github:NextAlone/Nagram-qt
```

程序在隔离的 FHS 环境里运行，由 Nix 更新，应用内的自动更新是关闭的。其他发行版上即使装了 Nix 也不要这样安装：包里不带图形驱动，找不到时程序一启动就退出。

AUR 和 Nix 的包在本版本发布后由 CI 更新，会比本页晚几分钟。

### Fedora、RHEL、openSUSE

```bash
sudo dnf install ./Nagram-7.4.6.1-linux-x86_64.rpm
```

openSUSE 用 `zypper install`。安装后运行 `Nagram`，由系统包管理器更新。包没有签名，安装本地文件时会提示跳过签名检查。

### 其他 Linux 发行版

解开 `tar.xz`，运行 `Nagram/Nagram`，旁边的 `TelegramDesktop` 文件夹要一起保留。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
