Nagram Desktop 7.3.5.2，基于 Telegram Desktop 7.3.5。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里列出相对上一个正式版 [7.3.3.2](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.3.3.2) 的全部变化，包括测试版 [7.3.5.1-beta](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.3.5.1-beta) 的内容。

功能主要在 macOS 上实际运行过，Windows 和 Linux 只通过了编译、单元测试和启动冒烟测试。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 反馈。

## 上游

升级到 Telegram Desktop 7.3.5（包含 7.3.4 测试版）。7.3.3.2 已经带上的会话列表搜索标签、代码块缩进和媒体查看器保存快捷键等改动，这里不再重复。

- 聊天默认改用新的聊天视图，发出的文字消息会“飞入”自己的气泡。可以在“设置 → 高级 → 实验性设置”里关闭“New chat view”，换回旧视图。Nagram 的功能在两种视图里都可用。
- 小程序在 Windows 和 macOS 上会请求摄像头和麦克风权限。
- 资料页的音乐和余额改为显示在按钮下方的胶囊里。
- 群组和频道可以用表情作为资料头像。
- 编辑消息时可以恢复已删除的网页预览。
- 机器人菜单按钮可以按住后拖动选择命令。
- 定时发送的时间滚轮转过午夜时，日期自动跳到下一天。
- 共享媒体的各个标签和右侧栏支持深层链接；机器人论坛的话题可以通过 `t.me/bot/topic` 链接打开。
- 附件菜单总是显示，列出当前可用的操作。
- 合成收藏品时可以选择主收藏品。
- 打开不带参数的 `@wallet` 链接会进入钱包窗口。
- 富文本编辑器里可以用 Backspace 删除分隔线。
- 代码块里的 diff 也会高亮，并限制了语法高亮的计算量。
- 带“举报垃圾消息”提示条的聊天：机器人按钮不可点，不显示对方的表情状态。
- 发送位置时去掉了选择地点的功能。
- 带话题的机器人的消息会显示通知；在其他设备上读过的话题消息，通知会被撤回。
- 导出迁移过的群组时，包含迁移前旧群的历史。
- 修复：
  - 自定义下载文件夹等设置在更新后被重置。
  - Windows：窗口最大化时抖动；通知跑出屏幕；在缩放不同的屏幕上，窗口位置恢复到工作区之外；D3D11 解码器重建后 DXVA2 回退失效。
  - 复制已被删除的消息的图片、照片菜单里的“恢复原图”无效、检查清单未修改时保存报错。
  - 话题、子列表被删除时的多处崩溃，以及群组通话、媒体查看器、代理设置、Touch Bar 等处的崩溃。
- 安全：
  - 收到的 SVG 统一经过清理，限制 SVG 滤镜、样式表和虚线描边的计算量。
  - 显示文字被日期或表情替换的链接、非常见协议的链接、导入 HTML 里的本地文件，打开前都会确认。
  - 单实例本地通信需要双向认证，Linux 上拒绝其他用户的连接。
  - 为 FFmpeg、libvpx、WebRTC、Qt 的 HTTP/2 补上多项边界检查和安全补丁，brotli 升级到 1.2.1。

## 修复

- 打开“无限收藏贴纸”后，把本地收藏的贴纸删光（或它们全部同步到服务器收藏），之后每次启动都会崩溃。本地置顶清空时也有同样的问题。
- 某条广告规则的正则表达式超出匹配预算时，整条消息会退回原文，其他规则的替换也一起失效。现在只跳过这一条，日志里会写出规则名。
- 打开“隐藏贴纸时间”后，收到的贴纸旁仍留着一个空的灰色圆角框。
- 多个文件合并发送并带文案时，右键菜单里没有“翻译”。
- 新聊天视图里，频道底部的“讨论”按钮和“保存阅读位置”不起作用。
- 打开“移动已读/表情列表到消息菜单顶部”后，列表没有排在消息菜单的最上方，而是在回复等操作之后。

| 平台 | 文件 |
| --- | --- |
| macOS（Apple 芯片与 Intel） | `Nagram-7.3.5.2-macos.dmg`（磁盘镜像）、`Nagram-7.3.5.2-macos.zip` |
| Windows x64 | `Nagram-7.3.5.2-windows-x64-setup.exe`（安装程序）、`Nagram-7.3.5.2-windows-x64.zip`（便携版） |
| Windows ARM64 | `Nagram-7.3.5.2-windows-arm64-setup.exe`（安装程序）、`Nagram-7.3.5.2-windows-arm64.zip`（便携版） |

名字以 `td-update-` 开头的文件是给应用内更新用的，不需要手动下载。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Arch Linux（AUR）

包名是 `nagram-desktop-bin`，安装的就是本页的 Linux 发行包：

```bash
yay -S nagram-desktop-bin
```

没有 AUR 助手时：

```bash
git clone https://aur.archlinux.org/nagram-desktop-bin.git
cd nagram-desktop-bin
makepkg -si
```

这样装的由 pacman 更新，应用内的自动更新是关闭的。

### Nix

仓库自带 flake，安装的同样是本页的 Linux 发行包。仅 NixOS 可用（x86_64-linux），需要启用 flakes：

```bash
nix run github:NextAlone/Nagram-qt
```

装进用户环境：

```bash
nix profile install github:NextAlone/Nagram-qt
```

在 NixOS 或其上 home-manager 的 flake 里，把 `github:NextAlone/Nagram-qt` 加为输入，然后使用 `packages.x86_64-linux.default`。程序在隔离的 FHS 环境里运行，由 Nix 更新，应用内的自动更新是关闭的。

其他发行版上即使装了 Nix 也不要这样安装：包里不带图形驱动，只从 NixOS 放驱动的 `/run/opengl-driver` 读取，找不到时程序一启动就退出。这些系统请用上面的 AUR 包或下面的 `tar.xz`。

AUR 和 Nix 的包在本版本发布后由 CI 更新，会比本页晚几分钟。

### 其他 Linux 发行版

解开 `tar.xz`，运行 `Nagram/Nagram`。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
