Nagram Desktop 7.3.3.2，基于 Telegram Desktop 7.3.3。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里列出相对上一个正式版 [7.2.10.3](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10.3) 的全部变化，包括测试版 [7.3.0.1-beta](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.3.0.1-beta) 和 [7.3.3.1-beta](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.3.3.1-beta) 的内容。

功能主要在 macOS 上实际运行过，Windows 和 Linux 只通过了编译、单元测试和启动冒烟测试。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 反馈。

## 上游

升级到 Telegram Desktop 7.3.3（包含 7.3.0、7.3.1、7.3.2），并同步了 7.3.3 之后开发分支上的改动。

### 7.3.0

上游这一版的更新记录只写了“Money”，下面按上游的提交整理。

- 钱包（Money）：内置的 Gram 钱包，在单独的窗口里显示余额（可换算成法币）、交易记录和收藏品。入口只在 Telegram 服务端对账号开放时出现。
  - 收发 Gram：从主菜单、资料页或私聊的附件菜单发送，可以填 Telegram 用户、钱包地址或 `.ton` 名字，附带的留言默认加密；转账在聊天里显示为卡片。
  - 打开 `ton://` 转账链接会进入发送界面；支持用 TON Connect 连接外部应用，并在钱包里查看和断开已连接的应用。
  - 密钥：导入或查看恢复短语，开启或关闭加密备份；钱包密钥由本地密码保护，macOS 可用 Touch ID、Windows 可用 Windows Hello 解锁。设置本地密码时显示强度提示。
- 消息暂存：输入框里写到一半的消息（包括待发送的文件）可以先暂存起来，稍后取回，有对应的按钮和快捷键。
- 图片与视频编辑器：
  - 可以把聊天消息和链接预览放到画布上。
  - 可以加音轨并调节音量；视频片段可以在时间线上裁剪，时间线支持滚轮缩放和直接输入时间。
  - 画布可以扩展到图片之外，按住 Shift 拖动时吸附参考线，按 Backspace 删除选中的项目，新增快捷键说明。
- 小程序：外部窗口的菜单、全屏、弹窗和加载提示有多处改进；小程序打开链接和下载文件需要用户操作；Linux 上会询问媒体和位置权限。
- 富文本消息：链接按钮显示网址提示并可复制链接，识别 TON 地址，修正气泡边缘的宽度、圆角和边距。
- 其他：输入时机器人菜单按钮会收窄；更多对话框可以按 Enter 提交；调过颜色的主题可读性更好。
- 修复：
  - 多处崩溃：即时预览编辑器、图片编辑器、分享框搜索、聊天列表的视频头像、没有屏幕时的通知、共享媒体跳转等。
  - 读到损坏的应用设置时不再死循环。
  - 同时编辑时不再丢失最新的草稿。
  - 含相对日期的富文本消息不再卡死。
- 依赖：Qt 6.11.2、OpenSSL 3.5.9，WebRTC、ANGLE、xz、ada 等同步更新。

## 新增

- 顶部栏按钮：聊天顶部栏的按钮改为自选和排序，可以在“聊天”设置里或右键按钮调整，默认不显示。可选的操作包括跳转到日期、跳转到消息、文件和链接，以及有权限时才出现的群组管理入口；放不下的按钮收进“更多”菜单。
- 跳转到消息：输入消息 ID（可带 `#`）或粘贴消息链接即可跳转。找不到消息时给出提示；指向其他聊天、评论或讨论串的链接会在对应位置打开。
- 群管理：在你可以封禁成员的超级群组里，右键成员头像或提及可以“修改权限”和“封禁或删除消息”，即使对方的消息已经不在了也能操作；移除成员时可以一并删除其消息。三处入口各有开关，默认关闭。
- 消息菜单新增“此用户的其他消息”，在群组和超级群组里搜索该发送者的消息。
- 显示消息 ID 改为三选一：关闭、在时间提示中、在气泡中（时间后面）。
- 消息详情新增 JSON 按钮，从 Telegram 重新获取这条消息并显示原始数据。
- 列表时间显示秒：会话列表里显示时间的行带上秒。
- 不发送我的输入和上传状态：对方不会看到你正在输入、录制、上传或选择贴纸，不影响已读回执和在线状态。
- 跳过打开链接确认：点击文字下隐藏的链接时不再询问，网站登录确认和链接规则仍会询问。
- 在窗口分栏中显示设置：设置首页显示在会话列表位置，各页在聊天栏中打开，不再弹窗。
- 设置项可以右键“复制链接”，链接格式与 Nagram Android、iOS 相同；打开链接会跳到对应设置并高亮。
- 搜索框圆角：调整会话列表和聊天内搜索框的圆角，重启后生效。
- 在联系人列表中标记双向联系人。
- 加高提及、话题标签和命令的候选列表（从 4.5 行加到 8.5 行）。
- 文件夹里通过“最近会话”出现的会话，右键可以“从最近会话中移除”。
- 安装最新改动的构建：在“安装测试版”下面新增开关，打开后会自动更新到默认分支的每次构建。
- 注册时间估算：Telegram 没有提供某个用户的注册月份时，资料页按用户 ID 估算并标明“估算”，显示为“约”“早于”或“晚于”某个月份。开关仍是原来的“显示注册时间”。
- 托盘图标换成了新的 Nagram 图标，包括 macOS 菜单栏图标和单色图标的未读、静音状态。
- 多选消息后的复读和无引用转发：
  - 多选栏的“转发”后面新增“复读”“无引用复读”“无引用转发”“复制”四个按钮，带选中数量；所选消息不能转发时不显示，窗口太窄时从后往前隐藏。“频道中不提供复读”同样生效。
  - 多选后的右键菜单也提供这三项操作，与单条消息菜单一样默认隐藏，可以在消息菜单设置里打开。
  - “复读”把所选消息转发回当前聊天；“无引用复读”逐条作为新消息发送；“无引用转发”打开选择聊天窗口，转发时隐藏原发送者。用多选栏按钮复读或转发后会退出多选。
  - 打开“复读前确认”时会先询问。

## 改进

- inline 机器人规则与 Nagram Android 对齐：去掉规则数量、匹配条件数量和长度的限制，多条规则可以用同一个机器人，按整段消息文字匹配；新规则默认启用并排在最前。
- 转发的消息在“转发自”标题后显示原消息的时间（今天只显示时间，昨天显示“昨天”），不再替换气泡里的时间，与 Nagram Android 一致。

## 修复

- “隐藏代理赞助频道”之前不起作用，现在会隐藏 MTProxy 的赞助频道，公共服务公告照常显示。
- 设置搜索可以从中文标题的任意位置匹配。
- “最近操作”页面的返回按钮背景与顶部栏颜色不一致。
- “最近会话”菜单项的图标。
- Windows：任务栏上的应用图标；Qt 6 构建里网页窗口点击无效。
- 消息菜单里的“重复”现在立刻显示发出的消息，不再等服务器返回。带相册或隐藏来源的转发同样如此。

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Arch Linux（AUR）

包名是 `nagram-desktop-bin`，安装的就是本页的 Linux 发行包：

```bash
yay -S nagram-desktop-bin
```

没有 AUR 助手时：

```bash
git clone https://aur.archlinux.org/nagram-desktop-bin.git
cd nagram-desktop-bin
makepkg -si
```

这样装的由 pacman 更新，应用内的自动更新是关闭的。

### Nix

仓库自带 flake，安装的同样是本页的 Linux 发行包。仅 NixOS 可用（x86_64-linux），需要启用 flakes：

```bash
nix run github:NextAlone/Nagram-qt
```

装进用户环境：

```bash
nix profile install github:NextAlone/Nagram-qt
```

在 NixOS 或其上 home-manager 的 flake 里，把 `github:NextAlone/Nagram-qt` 加为输入，然后使用 `packages.x86_64-linux.default`。程序在隔离的 FHS 环境里运行，由 Nix 更新，应用内的自动更新是关闭的。

其他发行版上即使装了 Nix 也不要这样安装：包里不带图形驱动，只从 NixOS 放驱动的 `/run/opengl-driver` 读取，找不到时程序一启动就退出。这些系统请用上面的 AUR 包或下面的 `tar.xz`。

AUR 和 Nix 的包在本版本发布后由 CI 更新，会比本页晚几分钟。

### 其他 Linux 发行版

解开 `tar.xz`，运行 `Nagram/Nagram`。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
